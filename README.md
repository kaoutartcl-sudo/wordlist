# Wordlist / Educational Handshake Batch Test

## اختبار المصافحة على دفعات

افتح **Actions → Educational Handshake Batch Test → Run workflow**.

- مجموعة الأحرف ثابتة لهذه التجربة: `ODRACodkeni78421306` (19 حرفًا ورقمًا).
- الطول: من 8 إلى 11، بالترتيب ثم حسب ترتيب الأحرف أعلاه.
- حجم الدفعة: مليون كلمة؛ يتم حذف ملف الكلمات المؤقت بعد الاختبار.
- `batches`: عدد الدفعات في التشغيل، من 1 إلى 5 (الافتراضي 1).
- `start`: موضع البداية؛ اتركه 0 في أول تشغيل.
- `resume_run`: رقم التشغيل السابق لاستكمال ملف `checkpoint` منه. اتركه فارغًا أول مرة. تجد الرقم في رابط التشغيل: `/actions/runs/NUMBER`.

بعد التشغيل، اعرض **Summary** لمعرفة النتيجة وموضع الاستكمال. احتفظ بملف `checkpoint`؛ يبقى متاحًا 30 يومًا. يمكن استخدام `next_start` يدويًا في `start` إذا انتهت صلاحية الملف، مع ترك `resume_run` فارغًا.

حالات النتيجة:

| الحالة | المعنى |
|---|---|
| `batch_complete` | انتهى اختبار الدفعات المطلوبة دون تطابق؛ يمكن الاستكمال |
| `found` | عُثر على تطابق وتوقف الاختبار؛ كلمة المرور لا تُنشر |
| `time_limit_incomplete_batch` | انتهى الوقت داخل دفعة؛ تُعاد هذه الدفعة عند الاستكمال لتجنب تجاوز كلمات غير مختبرة |
| `capture_or_tool_error` | لم تؤكد الأداة اكتمال الاختبار؛ لا يتم تقديم موضع الاستكمال |
| `exhausted` | اكتملت كل التركيبات دون تطابق |

التشغيل يدوي ومحدود بـ18 دقيقة للاختبار (و25 دقيقة للمهمة كاملة)، ولا يعيد تشغيل نفسه تلقائيًا. التقدم محفوظ بعد كل دفعة مكتملة؛ الإلغاء القسري قد يمنع رفع آخر ملف تقدم.

## الخصوصية

حزم المصافحة الضرورية فقط محفوظة في السر `HANDSHAKE_CAP_B64`، وليست في المستودع. لا تُرفع المصافحة أو سجلات Aircrack الخام أو كلمة المرور المكتشفة كملفات نتائج. لا تتضمن النتائج العامة سوى تقدم الاختبار وإعداداته وبصمة الملف. يمكن لمن يملك صلاحية تعديل workflows استخدام أسرار المستودع؛ لذلك لا تمنح صلاحية التعديل لأشخاص غير موثوقين.
